# AcxiomCRM assignment mapping

| Assignment requirement | This project |
|---|---|
| Authentication | Spring Boot /api/auth/login + logout |
| Password hashing | BCrypt |
| Lockout | 5 failed attempts, 10-minute lockout |
| Roles | ADMIN, MANAGER, SALES_EXECUTIVE field |
| Customer CRUD | /api/customers |
| Lead management | /api/leads |
| Opportunity | /api/opportunities |
| Follow-up | /api/followups |
| Dashboard | /api/dashboard + Django page |
| REST API | Spring Boot REST controllers |
| Postman | Collection included |
| MySQL Workbench | SQL helper included |
| Client-side validation | HTML5/Django forms can be extended; Postman demonstrates server-side |
| Server-side validation | Jakarta Bean Validation + business rules |
| Audit | audit_logs table + /api/audit |
| Reports | pipeline endpoint + dashboard |
| Search | customer search parameter |
| Chart-ready data | dashboard/pipeline JSON |
